去背景
先看素材，再选处理方式 这里只放常用判断；模型和运行环境细节仍以 README 与 AI_MATTING.md 为准。

背景目标与后处理

自动取背景色
纯色背景优先使用，由画面边缘自动判断颜色。
手动指定颜色
自动取色不准时，明确指定绿、蓝、白或其他底色。
Luma 背景
亮特效配黑底选“抠除黑色”；暗素材配白底选“抠除白色”。
背景残留转黑
适合需要黑色边缘的 VFX，不适合普通彩色角色。
背景残留饱和度归零
降低背景色污染，通常比直接转黑更自然。
半透明转黑 / 不透明
用于特殊硬边风格；会损失柔光和半透明细节。

处理方式

Chroma
绿幕、蓝幕、白底、灰底等受控纯色背景，速度最快。
Luma
黑底或白底的火焰、闪电、粒子和亮部 VFX。
BiRefNet
真实背景或 AI 生成背景，主体轮廓明确时使用。
CorridorKey
标准绿幕或蓝幕，分别使用对应的 EZ-CorridorKey 模型重建前景、细化遮罩并去除幕布溢色。
不抠图
保留原始画面，只执行后续尺寸与批处理。

GIF
